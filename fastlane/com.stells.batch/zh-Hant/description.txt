Photos Plus是一款無限制的視頻和相機工具箱，具有快速高速批處理媒體編輯功能。 選擇工具，選擇所有必需的照片，然後點擊按鈕。 您可以為所有照片執行所需的一切。

當然，Photo Apps支持iOS 12和Siri Shortcuts。

工具簡介 - 將繼續增加。


相机
标准内置摄像头，支持深度效果，RAW捕捉，GPS元数据保存控制。


深度編輯器
可以在捕獲肖像後調整背景模糊的強度。


自动选择机器人（ASB）
ASB是一款多用途照片助手，可自動預測並從每個工具中選擇合適的照片。目前，發現者，清潔工，EXIF鬼和恢復工具支持這一點，未來支持範圍將繼續增加。


RAW編輯器
易於使用但功能強大的RAW照片編輯器，可為拍攝原始圖像提供許多優勢。 與JPEG圖像相比，無法實現編輯質量。


發現者
Finder可以從您的照片中提取每個有意義的信息，如電話號碼，地址，日期或URL，然後撥打電話，打開地圖或瀏覽網站甚至搜索航班。您也可以將它們全部保存為原始文本。

Finder操作列表
• 電話號碼 - 保存或編號或轉換為iOS聯繫人。
• 電子郵件地址 - 發送消息。
• 地址 - 在地圖上打開
• 日期 - 使用日曆保存為事件。
• URL - 使用瀏覽器打開。
• 航班號 - 搜索檢測到號碼的航班。
• 價格信息 - 檢測價格，並以匯率將其換成另一個價格。
許多行動將會更新！


變流器
Converter允許您將每種媒體格式（如視頻，實時照片，GIF）轉換為彼此。

轉換器列表
• 視頻 -> 實時照片
• 視頻 -> 壓縮視頻（.mp4）
• 視頻 -> GIF
• 現場照片 -> 視頻
• 現場照片 -> GIF
• GIF -> 實時照片
• GIF -> 視頻
• 連拍照片 -> 實時照片
• 連拍照片 -> GIF
• 連拍照片 -> 視頻
• 間隔拍攝視頻 -> 實時照片
• 間隔拍攝視頻 -> 壓縮視頻（.mp4）
• 間隔拍攝視頻 -> GIF
• 截圖圖像（無失色PNG） -> 壓縮JPG


清潔器
清潔器使您能夠查找和刪除各種不正確的照片，如果他們匹配了例如重複和類似的圖像，特寫照片或鎖屏拍攝！

清潔匹配清單
• 相似性
• 截圖
• 包括手電筒
• 使用內置攝像頭保存
• 鎖屏 - 採用iOS鎖定屏幕截圖。
• 太近距離的臉
• Sutter速度太慢
• 沒有聲音的視頻
• 短於1秒的視頻
• Instagram保存的視頻
• 所有未使用相機拍攝


GIF製造商
GIF Maker可以通過各種選項輕鬆快速地從照片或實時照片製作GIF圖像！然後您可以打開轉換器應用程序以轉換為實時照片或視頻等所有內容。

• 多張照片
• 爆裂照片
• 實時照片
• 定制質量和裁剪比例支持
• 幀延遲，方向（前進，後退，倒帶），重複控制


MemoCam
基於AI的角色信息識別MemoCam是一款相機工具，可讓相機準確檢測，提取和存儲所有重要信息，如電話號碼，電話，條形碼，地址，日期或URL，你。


EXIF Ghost
EXIF Ghost可讓您刪除包含照片的各種數據，包括私人信息。

• 選擇性元數據清除所有GPS，EXIF，TIFF支持屬性。


井號
从您选择的照片中查找和收集主题标签。


轉變
這種直觀但大規模的批量圖像變換工具可讓您快速旋轉和翻轉包括實時照片在內的大量媒體文件。編輯照片的數量沒有限制。

• 經過測試的處理能力：2000次+一次拍照。
• 針對多核處理進行了優化。這取決於iDevice模型。


Framer
Framer允许您调整大小并填充以适合各种尺寸的Instagram，Youtube或您需要的照片。


自動編輯器
如果需要更正照片，“自動編輯器”可讓您自動編輯。

• 自動增強
• 自動拉直
• 自動裁剪
• 自動消除紅眼


過濾器
在您想要的所有照片上應用高質量的濾鏡。此批處理工具對應用過濾器的照片數量沒有限制。

• 經過測試的處理能力：2000次+一次拍照。
• 針對多核處理進行了優化。這取決於圖像大小和iDevice模型。


PDFactory
PDFactory使用各種頁面選項從多個圖像製作PDF文檔。

• 頁面大小（例如，A4或美國法律），保證金，比例和佈局模式支持


還原
還原應用程序允許快速將大量已編輯的照片恢復為原始照片。此外，它可以幫助您自動選擇！
