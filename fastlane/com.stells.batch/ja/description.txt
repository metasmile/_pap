PAPSは、高速大規模なバッチ処理メディア編集機能を備えた無制限の、ビデオ、およびカメラツールボックスです。ツールを選択し、必要なすべての写真を選択し、ボタンをタップします。すべての写真に必要なすべてのものを行うことができます。


バッチツールの紹介 - これから非常に多様なツールが引き続き追加される予定です。


カメラ
デプスエフェクト、RAWキャプチャ、GPSメタデータ保存コントロールをサポートしている標準の内蔵カメラ。


自動選択ボット（ASB）
ASBは、各ツールの適切な画像を予測し、自動的に選択してくれる万能の画像を選択ヘルパーです。現在ファインダー、クリーナー、EXIFゴースト、復元ツールなどがこれをサポートし、今後サポート範囲が増え続ける予定です。


ファインダー
あなたの写真やスクリーンショットで電話番号、住所、日付、価格やURLなどのすべての意味のある情報を抽出し、電話をかけたり地図を開き、Webサイトを閲覧することができます。
そして、すべてテキスト形式で保存したり、私たちの言葉の翻訳をすることができます。

Finderの動作リスト

認識されたデータを
•電話番号 - iOSの連絡先に保存/変換する
•電子メールアドレス - メールメッセージを送信
•アドレス - 地図で開く
•日付 - カレンダーに保存
•URL - ブラウザで開く
•フライト番号 - フライトを検索する
•価格情報 - 価格を検出し、交換レートで別の価格に交換します。
他にもより多くの機能が更新されます。


コンバータ
コンバータを使用すると、動画、ライブ写真、GIFなどのすべてのメディア形式を相互に変換することができます。

コンバータのリスト
•動画 -> ライブ写真
•動画 -> 圧縮動画（.mp4）
•動画 ->  GIF
•ライブ写真 -> 動画
•ライブ写真 ->  GIF
•GIF -> ライブ写真
•GIF -> 動画
•バースト写真 -> ライブ写真
•バースト写真 -> GIF
•バースト写真 -> 動画
•タイムラプス動画 -> ライブ写真
•タイムラプス動画 -> 圧縮動画（.mp4）
•タイムラプス動画 -> GIF
•スクリーンショット画像（損失のないPNG） -> 圧縮されたJPG


クリーナー
クリーナーを使用すると、不正確な写真を探したり、削除することができます。（例えば、重複したり、類似した画像、近接写真またはロック画面のスクリーンショットなどを見つけて削除することができます。

クリーナーマッチングツールリスト
•類似性
•スクリーンショット
•フラッシュで撮った写真
•内蔵カメラで保存
•ロック画面 - iOSのロック画面のスクリーンショットをキャプチャします。
•顔があまりにも大きいクローズアップ
•遅すぎるシャッタースピード
•音がない動画
•1秒より短い動画
•Instagramによって保存された動画
•カメラで撮影していないすべての画像ファイル


GIF Maker
GIF Makerを使用すると、様々なオプションで写真やライブ写真をGIF画像にすばやく簡単に作成できます！次にコンバータアプリを開いて、ライブ写真や動画に変換することもできます。

•複数の写真
•バースト写真
•ライブ写真
•ユーザ定義の品質とトリミング比サポート
•フレームディレイ、方向（正方向、逆方向、巻き戻し）、繰り返し制御


EXIFゴースト
EXIFゴーストを使用すると、個人情報をはじめとする写真に含まれている様々な種類のデータを削除することができます。

•GPS、EXIF、TIFF、サポートのすべてのプロパティオプションのメタデータを削除。


Memo Cam
AIベースのテキスト情報認識カメラツールであるMemoCamを使用すると、電話番号、通貨、バーコード、住所、カメラの近くの日付またはURLなどの重要な情報をすべて正確に検出して抽出/保存することができます。


ハッシュタグ
選択した写真からハッシュタグを見つけて収集する。


回転
単純で大規模なバッチ画像の回転ツールは、ライブフォトや動画をはじめとするすべてのメディアファイルを迅速に回転することができます。更に編集する写真の数に制限はありません。

•テストされた処理能力：一度に2000個以上の写真。
•マルチコアプロセッシングに最適化されました。 iDeviceモデルによって異なります。


フレーマ
フレーマ允许您调整大小并填充以适合各种尺寸的Instagram，Youtube或您需要的照片。


自動エディタ
自動エディタを使用すると、写真を自動編集することができます。

•自動補正
•自動回転補正
•自動トリミング
•自動赤目除去


フィルタ
写真に、高品質のフィルターを適用します。フィルタを適用する画像の数に制限はありません。

•テストされた処理能力：一度に2000個以上の写真。
•マルチコアプロセッシングに最適化されました。画像のサイズとiDeviceモデルによって異なります。


PDFactory
PDFactoryは、様々なページオプションを利用して複数の画像からPDF文書を作成します。

•ページサイズ（例えば、A4または米国の法律）、マージン、サイズとレイアウトモードをサポート


Revert
元に戻すアプリを使用すると、複数の写真を元の写真に迅速に復元することができます。また、自動選択ボットを利用すれば、自動的に素早く選択することもできます。
