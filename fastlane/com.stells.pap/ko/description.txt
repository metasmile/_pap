익숙한 iOS의 표준 UI로 설계된 포토앱스(Photo Apps- 약어:PA)는 광범위한 용도의 사진 앱으로 최신 기술로 제작 된 많은 하위 카메라 및 사진 응용 프로그램을 포함합니다.

물론, 최신 iOS 12와 시리 Shortcut을 지원합니다. Siri에세 이렇게 말해보세요.
"시리야, 라이프 포토로 셀카 찍어줘."

이제부터 여러분의 사진으로 모든 것을 하세요.


파인더
Finder를 사용하면 사진에서 전화 번호, 주소, 날짜 또는 URL과 같은 모든 의미있는 정보를 추출한 다음 전화를 걸거나 지도를 열고 웹 사이트를 탐색 할 수 있습니다. 그리고 모두 원시 텍스트로도 저장할 수 있습니다.

Finder 동작 목록

인식된 데이터를
• 전화 번호 - iOS 연락처로 저장 / 변환하기
• 전자 메일 주소 - 이메일 메세지 보내기
• 주소 - 지도에서 열기
• 날짜 - 캘린더에 저장
• URL - 브라우저에서 열기
• 항공편 번호 - 항공편을 검색하기
앞으로 더욱 많은 액션들이 업데이트 됩니다.


컨버터
컨버터를 사용하면 비디오, 라이브 사진, GIF와 같은 모든 미디어 형식을 서로 변환 할 수 있습니다.

변환기 목록
• 비디오 -> 라이브 사진
• 비디오 -> 압축 비디오 (.mp4)
• 비디오 -> GIF
• 라이브 사진 -> 비디오
• 라이브 사진 -> GIF
• GIF -> 라이브 사진
• GIF -> 비디오
• 버스트 사진 -> 라이브 사진
• 버스트 버스트 -> GIF
• 버스트 사진 -> 비디오
• 타임랩스 비디오 -> 라이브 사진
• 타임랩스 비디오 -> 압축 비디오 (.mp4)
• 타임랩스 비디오 -> GIF
• 스크린 샷 이미지 (손실없는 PNG) -> 압축 된 JPG


클리너
클리너를 사용하면 여러 종류의 부정확 한 사진을 찾거나 삭제할 수 있습니다 (예 : 중복되거나 유사한 이미지, 근접 사진 또는 잠금화면 스크린샷 이미지).

클리너 매처리스트
• 유사성
• 스크린 샷
• 손전등 포함
• 내장 카메라로 저장 (PA 내 에서)
• 잠금 화면 - iOS 잠금 화면으로 스크린 샷을 캡처합니다.
• 클로즈 업 페이스가 너무 큼
• 너무 느린 셔터 속도
• 소리가없는 비디오
• 1 초보다 짧은 비디오
• Instagram이 저장 한 비디오
• 카메라로 촬영하지 않은 모든 것


GIF 제작기
GIF 제작기를 사용하면 다양한 옵션으로 사진이나 라이브 사진에서 GIF 이미지를 쉽고 빠르게 만들 수 있습니다! 그런 다음 변환기 앱을 열어 라이브 사진이나 비디오와 같은 모든 것을 변환 할 수 있습니다.

• 여러 사진
• 사진 버스트
• 라이브 사진
• 사용자 정의 품질 및 자르기 비율 지원
• 프레임 지연, 방향 (정방향, 역방향, 되감기), 반복 제어


EXIF 고스트
EXIF 고스트를 사용하면 개인 정보를 비롯한 사진이 포함 된 모든 종류의 데이터를 제거 할 수 있습니다.

• GPS, EXIF, TIFF 지원의 모든 속성에 대한 선택적 메타 데이터 제거.


회전
이 간단하지만 대규모 배치 이미지 회전 도구를 사용하면 라이브 포토나 비디오를 비롯한 모든 미디어 파일을 신속하게 회전하고 뒤집을 수 있습니다. 편집 할 사진 수에는 제한이 없습니다.

• 테스트 된 처리 용량 : 한 번에 2000 개 이상의 사진.
• 멀티 코어 프로세싱에 최적화되었습니다. iDevice 모델에 따라 다릅니다.


자동 편집기
자동 편집기를 사용하면 사진을 수정해야하는 경우 자동으로 편집 할 수 있습니다.

• 자동 향상
• 자동 회전 교정
• 자동 자르기
• 자동 적목 현상 제거


필터
원하는 모든 사진에 고품질 필터를 적용하십시오. 이 일괄 처리 도구는 필터를 적용 할 사진 수에 제한이 없습니다.

• 테스트 된 처리 용량 : 한 번에 2000 개 이상의 사진.
• 멀티 코어 프로세싱에 최적화되었습니다. 이미지 크기 및 iDevice 모델에 따라 다릅니다.


PDFactory
PDFactory는 다양한 페이지 옵션으로 여러 이미지에서 PDF 문서를 만듭니다.

• 페이지 크기 (예 : A4 또는 US Legal), 여백, 크기 및 레이아웃 모드 지원


전화 통화
전화 통화를 사용하면 수많은 사진에서 전화 번호를 정확하게 수집 할 수 있습니다. 그 다음 단지 전화 걸면 됩니다!


카메라
라이브 사진 캡처기능을 포함한 견고한 표준형 내장 카메라.


Revert
되돌리기 앱을 사용하면 여러 장의 사진을 원래 사진으로 빠르게 복원 할 수 있습니다. 또한, 자동 선택 봇을 이용하면 자동으로 빠르게 선택 할 수 있습니다.



마지막으로 ... "자동 선택 봇 (ASB)"을 소개합니다.
ASB는 응용 프로그램의 현재 컨텍스트에서 적합한 항목을 선택하기 위한 다목적 사진 선택 도우미 입니다. 현재 여러 앱, Finder, Cleaner, EXIF 고스트, 전화 통화 및 복원 앱이 이를 지원합니다. 앞으로 대부분의 앱이 이를 지원할 계획입니다.

이제 각 앱의 제어판을 켜십시오!
